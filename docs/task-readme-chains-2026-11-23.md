## Что сравнивать

| конфиг | что это |
|---|---|
| point-a-prime.json (A′) | эталон: FP8, SDPA, 704×1280, 2 шага, TAEHV |
| live2.json | «ours» из README: W4A4, S2, NTK-aware 1.1, 512×928 (пакет 512x928-sage-cross-ntk110) |
| 544x960-win32-live.json | новый Live: W4A4, PI, 544×960, окно 32 |

Видео README собраны 04.11 (коммит 4e5a45c) из той же точки, что live2.json, но старой сборкой, поэтому live2 гоняется заново.

## Метрика и отчёт

$$ L = \mathrm{LPIPS}_{\mathrm{align}} + (1 - \mathrm{DINO}) $$

против эталона A′, по каждой сцене, плюс fps. Отчёт в стиле README: формулы и таблица «конфиг × сцена → L, fps». Итог одним длинным mp4 (сетка, метрики сверху), открыть в VLC в новом окне.

Для справки: `docs/report-2026-11-17-metric.md`, на первых трёх чанках 0.426 (544×960) против 0.483 (512×928).
