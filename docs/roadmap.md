# План реализации

## 0. Спецификация

- [ ] Зафиксировать upstream commit и checkpoint revision.
- [ ] Прочитать config и state_dict без загрузки всей модели в VRAM.
- [ ] Выписать patch size, dim, ffn_dim, heads, layers, форматы conditioning.
- [ ] Проверить лицензии перед переносом исходного кода.
- [ ] Согласовать dtype и допуски сравнения с оригиналом.

## 1. Блок

- [ ] Реализовать нормализации, RoPE, attention, FFN, timestep modulation и residual.
- [ ] Реализовать явное сопоставление параметров оригинала и своей реализации.
- [ ] Проверить отсутствующие и лишние параметры, формы и dtype.
- [ ] Сравнить промежуточные тензоры и выход на одинаковых входах.
- [ ] Проверить реальные активации с нескольких шагов диффузии.
- [ ] Добавить baseline времени и пиковой VRAM блока.

## 2. Полный денойзер

- [ ] Patch embedding, text/time conditioning, стек блоков, output head, unpatchify.
- [ ] Проверить полный forward против оригинала.
- [ ] Проверить размещение памяти и при необходимости добавить offload.

## 3. Генерация

- [ ] Подключить готовые текстовый энкодер, scheduler и VAE.
- [ ] Зафиксировать prompt, seed, число кадров, разрешение и число шагов.
- [ ] Сравнить латенты и итоговые видео; один seed не считать полной проверкой качества.

## 4. Оптимизация

- [ ] Профиль eager baseline.
- [ ] torch.compile: точность, прогрев, steady-state latency, VRAM.
- [ ] Перенести квантователь из учебного INT8-DiT после независимой проверки.
- [ ] W8A8 Linear: INT8 GEMM, скейлы и bias; сравнить весь вызов с FP16.
- [ ] Повторить измерения FFN, блока и полного денойзера.
- [ ] Рассматривать CUDA/CUTLASS только с конкретной гипотезой из профиля.

## Формат отчёта

Для каждого эксперимента: commit, среда, конфигурация, формы входа, проверка корректности, время первого запуска, медиана и разброс после прогрева, пиковая память, ошибка и вывод. Не менять одновременно алгоритм, число шагов и точность без отдельных сравнений.
