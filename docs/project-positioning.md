# Выбор проекта: 16 сентября 2026

## Вывод

Самостоятельное воспроизведение Wan2.1 — учебная база, а не заявка на новую frontier-модель. Для портфолио предлагается цель: воспроизводимый video inference runtime с реальными весами, профилированием, контролем VRAM и качества; затем потоковая генерация и KV-cache. Это инженерная рекомендация, не требование Higgsfield.

## Проверенные альтернативы

- [Wan2.2](https://github.com/Wan-Video/Wan2.2): официальный пример TI2V-5B 720P требует минимум 24 ГБ VRAM даже с указанными offload-настройками. Это не нижняя граница для всех сторонних реализаций, но существенно выше нашей машины.
- [HY-WorldPlay](https://github.com/Tencent-Hunyuan/HY-WorldPlay): action-conditioned генерация следующего чанка и восстановление памяти контекста. Для описанного Hunyuan AR inference с 125 кадрами указаны 72 ГБ при sp=1, 34 ГБ при sp=4 и 28 ГБ при sp=8. Есть отдельный облегчённый WAN-5B pipeline; числа Hunyuan нельзя автоматически переносить на него.
- [NVIDIA Cosmos](https://github.com/NVIDIA/Cosmos): актуальный репозиторий описывает Cosmos 3, multimodal reasoning/generation и action modeling. Семейство 64B/16B/4B; даже младшую модель нельзя считать готовым решением для 8 ГБ лишь по числу параметров. Это расширяет задачу в сторону Physical AI, а не просто ускорения видеогенерации.
- [Self Forcing](https://github.com/guandeh17/Self-Forcing): исследовательская база авторегрессионной видеодиффузии; подходит как следующий ориентир для streaming inference. Совместимость checkpoint и causal-механики потребует отдельной реализации, обычные веса Wan нельзя объявлять готовой streaming-моделью.

## Что делаем сейчас

Сохраняем Wan2.1 T2V-1.3B как локально доступный baseline и воспроизводим его денойзер. Замеряем Linear, attention, блок, полный проход и переносы памяти. Переносим доказанные оптимизации вверх и контролируем накопление ошибки на шагах диффузии.

## Следующий показательный этап

Отдельный режим с авторегрессионными весами: latency первого чанка, устойчивый FPS, p50/p95 задержки, рост KV-cache, управление памятью и качество длинной последовательности. Переход требует соответствующего checkpoint; обучение с нуля пока не планируется.

Не называть обычный text-to-video runtime интерактивной world model без action conditioning и соответствующей проверки.
