# Вектор токена и головы

Патч латента → patch embedding → токен из 1536 чисел.

```
токен (1536 чисел)
├── голова 1   (128 чисел)
├── голова 2   (128 чисел)
├── ...
└── голова 12  (128 чисел)
```

1536 / 12 = 128: каждая голова получает свои 128 чисел токена.

Дальше внутри одной головы 128 чисел делятся между тремя осями позиции (кадр, высота, ширина). Сколько чисел на каждую ось, пока открыто.

RoPE крутит пары чисел внутри q и k каждой головы, поэтому позиция попадает в голову через её 128 измерений.
