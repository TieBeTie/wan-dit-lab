# E26. Live W4A4 и Sage 2, 480×832

scripts/live_video.py, модель по умолчанию longlive2 теперь: LongLive-2.0-5B на 2 шага (model_te.pt),
блоки из пакета W4A4 v2 целиком на GPU (2,8 ГБ, без подкачки из RAM), Sage 2 прямо по FP8-кэшу (E25),
cross-attention один раз на промпт, RoPE во float32. Прежний вариант (4 шага, FP8, 12 блоков из RAM): longlive2_fp8.

Проверка без окна (та же загрузка, что в Live; скрипт и кадры в outputs/experiments/2026-10-20/21_Live_W4A4_Sage_480p):
первый чанк 25,7 с (компиляция), затем 1,67–1,98 с на чанк из 32 кадров;
с полным кэшем 16,4 кадра/с против 4,6 у FP8 (E17). Пик памяти GPU 5,83 ГиБ.
Окно Live и смена сцены в этом виде не проверялись.
