# E30. Стартовая точка W4A4 704×1280 и отложенные шаги

Рамка пользователя: пространство факторов конфига; ищем стартовую точку у вершины качества и спускаемся по одному
фактору. По сетке grid-final-2026-11-03.mp4 он выбрал стартовой точкой W4A4 704×1280 (W4A4 на глаз не хуже FP8,
главное различие в разрешении).

Стартовая точка: configs/experiments/director-original/point-b2-w4a4-sage-704x1280.json. W4A4, Sage 2 +
отдельное ядро RoPE LongLive, cross-attention SDPA efficient, T5 BF16, RoPE без растяжения, KV FP8.

| Точка | fps | Оценка трёх видео (57 чанков, 1815 кадров) |
|---|---|---|
| W4A4 704×1280, T5 BF16 (старт) | 5.41 | 5.6 мин |
| то же, T5 INT8 | 5.58 | 5.4 мин |
| W4A4 512×928, остальное как старт | 11.29 | 2.7 мин |
| FP8 512×928 | 6.28 | 4.8 мин |
| FP8 704×1280 (B, E29) | 2.17 | 13.9 мин |
| рабочий W4A4 512×928, sage_rope, Sage cross, T5 INT8 | около 14.5 (только чанки 1–2, на 3-м OOM) | |

Отладочный bench, старт, T5 BF16 против INT8 (8 чанков): чанк 5.46 / 5.48 s, опозданий копий весов 0 из 360 в
обоих, первый промпт 3.19 / 1.98 s, смена промпта 2.86 / 1.63 s, закреплённая RAM 5.96 / 5.67 GiB, T5 в VRAM
2.96 / 3.39 GiB (auto), пик VRAM 5.56 / 6.09 GiB. Минимум без опозданий: VRAM около 2.6 GiB, RAM около 5.9 GiB
закреплённой (сами буферы KV FP8 4.985 GiB); веса W4A4 с SSD.

## Отложенные шаги (сделать в конце, когда остальное оптимизировано)

- T5 BF16 → INT8: fps не меняет, смена промпта вдвое быстрее, RAM меньше на 0.29 GiB; цена только в том, как он
  слушается промпта (видно лишь глазами).
- Оффлоадинг T5 под задержку промпта: резерв VRAM 0.1875 → 0.1 (около +3 строк T5 на GPU); строки T5 в RAM вместо
  SSD (нужна правка кода). Не измерено: замедляет ли T5 чанки, когда в Live считается одновременно с видео.
- Растяжение RoPE: после выбора стартовой точки.
- Соседи, конфиги готовы, не запускались: cross-attention Sage 2 (point-b2c-w4a4-sagecross-704x1280.json), Sage 2
  со слитым RoPE (point-b2r-w4a4-sagerope-704x1280.json).

Ограничение машины: на 704×1280 KV FP8 (4.985 GiB, или 5.353 GB) влезает в RAM только с резервом RAM 0 и закрытыми программами;
минимум свободной RAM в прогонах 0.68–0.70 GiB.

## Слитое ядро Sage 2 + RoPE

`sage_rope_sm89` вместо `sage_sm89` + RoPE LongLive: 5.46 против 5.41 fps. Ошибка к точному attention на одном
вызове 5.228% против 5.234%: точность равна, видео расходятся от разных мест округления (Q в INT8 из FP32 вместо BF16).
Пользователь отложил этот фактор: задача для Astra в Lean, как слить ядро с меньшей ошибкой.

## Гипотеза: модель обучена на квантизации

Чекпойнт model_te.pt взят из LongLive-2.0-5B-NVFP4-S2. README LongLive 2.0 (reference/LongLive/LongLive2.0):
NVFP4 и для AR-обучения, и для дистилляции, NVFP4-инференс W4A4 и NVFP4 KV-кэш. Это объясняет, почему W4A4 на глаз
не хуже FP8: меньшая ошибка к FP32 не обязательно лучшее видео, эталоном для этого чекпойнта может быть его NVFP4-путь.
Не проверено: формат обучения (NVFP4 с блочными масштабами против нашего W4A4 SVDQuant) и квантован ли в обучении attention.
